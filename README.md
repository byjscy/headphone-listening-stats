# headphone-listening-stats
在浏览器本地统计 Apple 健康记录中的耳机使用时长和音量

## 程序功能

- 按耳机查看累计使用时长、使用次数、使用趋势和播放音量。
- 支持按日期筛选，可快速查看最近 7 天、30 天、90 天、1 年或全部记录。快捷日期以所选耳机的最近记录日为截止日。
- 支持导入 Apple 健康导出的 ZIP 文件或解压后的 `export.xml`。点击「查看示例」可以先体验统计页面。

## 使用方法

1. 在 iPhone 上打开「健康」App，点击右上角的个人头像，滑到底部选择「导出所有健康数据」。
2. 将导出的 ZIP 文件传到电脑。
3. 在 GitHub 上打开 [HeadphoneStats.html](HeadphoneStats.html)，点击文件页右上角的下载按钮，将 HTML 保存到电脑。
4. 用新版 Edge 或 Chrome 打开下载的 HTML，点击「导入 Apple 健康数据」，选择 ZIP 文件或解压后的 `export.xml`。
5. 导入完成后，选择要查看的耳机和日期范围。如果浏览器无法解压 ZIP，可先手动解压，再导入 XML。

## 统计口径

- 同一副耳机的相邻播放记录间隔超过 3 分钟时，计为新的一次使用。使用时长只累计实际记录的播放区间，同一副耳机的重叠区间会去重。
- 平均音量按有音量读数的播放时长加权。超过 80 dB 的比例也以有音量读数的时长为分母。
- 如果导出记录缺少独立设备标识，同型号的耳机可能被合并统计。

## 数据隐私

程序在本机浏览器中读取和分析导出文件。使用时无需登录，健康数据不会上传到 GitHub。

本项目在开发过程中使用了 AI 辅助编写和整理文档。
